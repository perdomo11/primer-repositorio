# Primer Repositorio

Proyecto de práctica del curso de JavaScript de la UDB, creado para aprender a usar Git y GitHub: inicializar un repositorio, registrar cambios con commits y subirlos a GitHub.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Instrucciones para abrir el proyecto

1. Clona el repositorio:

   ```bash
   git clone https://github.com/perdomo11/primer-repositorio.git
   ```

2. Entra a la carpeta del proyecto:

   ```bash
   cd primer-repositorio
   ```

3. Abre el archivo `index.html` en tu navegador (doble clic sobre el archivo), o abre la carpeta en Visual Studio Code y usa la extensión **Live Server**.
